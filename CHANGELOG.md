# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [v1.0] - 2025-10-30

### Added
- Initial version of Ping Checker
- Hardcoded list of IP addresses
- Ping each IP using `subprocess.run()`
- Print response status to console
- Count and display number of successful responses

---

## [v2.0] - *Upcoming*

### Added
- Timestamp for each ping result
- Logging to `log.txt`
- User input for IP addresses
- Modularized code using functions
